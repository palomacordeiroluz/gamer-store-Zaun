ZAUN Gamer
E-commerce gamer desenvolvido como projeto acadêmico, com foco em design moderno e experiência de compra completa. A loja oferece periféricos, consoles e acessórios de alta performance para jogadores de todos os níveis.

Sobre o Projeto
A ZAUN Gamer nasceu com a missão de entregar desempenho, estilo e inovação para o público gamer. O projeto contempla desde a vitrine de produtos até um fluxo de checkout com múltiplas formas de pagamento.

Páginas:
Home — Hero section, catálogo de produtos, destaques da semana, planos e checkout
Portifolio — Catálogo completo com filtro por categoria
Sobre — História e informações da marca
Contato — Formulário de contato e canais de atendimento

Tecnologias Utilizadas:
HTML5
CSS3
JavaScript (Vanilla)
Google Fonts — Righteous, Barlow, Barlow Condensed
